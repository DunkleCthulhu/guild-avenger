# GrudgeBook 2.0.1

Книга Образ для World of Warcraft: Forever 1.60.1. Вона веде список ворожих персонажів і гільдій, попереджає про зустріч та рахує зафіксовані смерті персонажів.

## Встановлення

Розпакуйте `GrudgeBook-2.0.1.zip` у `World of Warcraft/_forever_/Interface/AddOns/`. Папка аддона зберігає назву `ForeverWatch`, щоб WoW завантажив старі дані. У меню аддонів він показується як **GrudgeBook**. Після оновлення введіть `/reload`, потім `/gb`. [Релізи GitHub](https://github.com/DunkleCthulhu/forever-watch/releases)

Під час першого запуску GrudgeBook переносить активні записи персонажів і гільдій та їхні коментарі зі списку Forever Watch у відповідний особистий або гільдійний список `GrudgeBookDB`. Автор і час старих записів невідомі. Перенесені персонажі стають доступними для поширення, коли WoW підтвердить їх як ворогів.

## Виявлення та лічильник

- Ворог зі списку або учасник позначеної гільдії запускає червоне сповіщення й рейд-тривогу, коли його взято в ціль, наведено курсор, з’явилася доступна іменна табличка або WoW надав доступну подію `UNIT_COMBAT`. Чат показує ім’я й коментар. Для одного ворога діє кулдаун 30 секунд.
- Сповіщення з’являється вгорі екрана. Перетягніть його лівою кнопкою миші, щоб змінити позицію. Для цього можна викликати сповіщення командою `/gb test`. Позиція зберігається між сесіями.
- **У ціль** і **Пінг небезпеки** доступні поза боєм. Кнопка пінгу з’являється, коли в цілі саме ворог зі сповіщення, а система пінгів WoW увімкнена. Натисніть її, щоб надіслати штатний пінг небезпеки на ціль.
- Лічильник використовує окремі події WoW `PARTY_KILL` і `UNIT_DIED` та об’єднує повідомлення про ту саму смерть. Для збільшення лічильника клієнт має надати читабельний ідентифікатор, який відповідає ворогу зі списку. `COMBAT_LOG_EVENT_UNFILTERED` у Forever зарезервований клієнтом.

## Керування

- Вікно `/gb` можна пересувати за заголовок і закривати через Esc. Список прокручується й показує ніки, коментарі, авторів, час додавання та кількість смертей.
- Під час відкриття або натискання **Додати** з порожнім полем підставляється ворожа ціль. **Гільдія з цілі** додає її гільдію. Обидві дії доступні через правий клік по портрету ворожої цілі або фокуса, якщо WoW надає відповідні дані.
- Щоб додати запис вручну, WoW має дозволяти перевірити, що персонаж протилежної фракції, доступний для атаки та перебуває поза вашою групою й гільдією. Використайте його повне ім’я та тримайте в цілі, під курсором, у фокусі або в межах видимої іменної таблички.

| Команда | Дія |
| --- | --- |
| `/gb` або `/gb ui` | Відкрити або закрити вікно. |
| `/gb add Ім’я Прізвище Коментар` | Додати ворога. Без аргументів використовується поточна ціль. |
| `/gb del Ім’я Прізвище` | Видалити запис. Без аргументів використовується поточна ціль. |
| `/gb guild add` | Додати гільдію поточної ворожої цілі. Назву в лапках можна доповнити коментарем. |
| `/gb guild del Назва гільдії` | Видалити гільдію зі списку. |
| `/gb share Ім’я Прізвище` | Запропонувати список гільдійцю. Без аргументів використовується поточна ціль. |
| `/gb test` | Показати тестове сповіщення та відтворити рейд-тривогу. |

**Поділитися переліком** підказує імена гільдійців онлайн. Виберіть підказку мишею або клавішею Tab і натисніть **Надіслати**. Кнопка **У чат гільдії** публікує посилання для всіх гільдійців з GrudgeBook. Посилання діє 30 хвилин, поки автор залишається онлайн у тій самій сесії.

В обох випадках передавання перевіряє відправника й одержувача за ростером і надсилає пакети з інтервалом 0,25 секунди. Одержувач бачить нові записи та оновлення лічильників і вибирає, що прийняти. Злиття зберігає локальний коментар і більший лічильник смертей. Обом гравцям потрібен GrudgeBook 2.0.0 або новіший.
