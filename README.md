# GrudgeBook 2.2.1

Книга Образ для World of Warcraft: Forever 1.60.1. Вона веде список ворожих персонажів і гільдій, попереджає про зустріч та рахує зафіксовані смерті персонажів.

## Встановлення

Розпакуйте `GrudgeBook-2.2.1.zip` у `World of Warcraft/_forever_/Interface/AddOns/`. Папка аддона зберігає назву `ForeverWatch`, щоб WoW завантажив старі дані. У меню аддонів він показується як **GrudgeBook**. Після оновлення введіть `/reload`, потім `/gb` або натисніть значок книги біля мінікарти. Значок можна перетягнути вздовж її краю. [Релізи GitHub](https://github.com/DunkleCthulhu/forever-watch/releases)

Під час першого запуску GrudgeBook переносить активні записи персонажів і гільдій та їхні коментарі зі списку Forever Watch у відповідний особистий або гільдійний список `GrudgeBookDB`. Автор і час старих записів невідомі. Перенесені персонажі стають доступними для поширення, коли WoW підтвердить їх як ворогів.

## Виявлення та лічильник

- Ворог зі списку або учасник позначеної гільдії запускає сповіщення, коли його взято в ціль, наведено курсор, з’явилася доступна іменна табличка або WoW надав доступну подію `UNIT_COMBAT`. Сповіщення показує портрет, ім’я, коментар і позначку високого пріоритету. Чат дублює ім’я й коментар. Для одного ворога діє кулдаун 30 секунд.
- Звичайний пріоритет типово використовує рейд-тривогу, а високий — окремий висхідний сигнал із чотирьох нот. У `/gb` натисніть **Звуки…**, щоб вибрати й прослухати штатні звуки WoW для кожного пріоритету. Звук також можна вимкнути окремо для збігів за персонажем і за гільдією або залишити лише для високого пріоритету. Запис конкретного персонажа визначає пріоритет, коментар і налаштування звуку, якщо він також є членом позначеної гільдії.
- Сповіщення з’являється вгорі екрана в напівпрозорій рамці WoW. Високий пріоритет виділено золотистою рамкою. Перетягніть сповіщення лівою кнопкою миші, щоб змінити позицію. Для перегляду обох стилів використайте `/gb test` і `/gb test high`. Позиція зберігається між сесіями.
- **У ціль** і **Пінг небезпеки** доступні поза боєм. Кнопка пінгу з’являється, коли в цілі саме ворог зі сповіщення, а система пінгів WoW увімкнена. Натисніть її, щоб надіслати штатний пінг небезпеки на ціль.
- Лічильник використовує окремі події WoW `PARTY_KILL` і `UNIT_DIED` та об’єднує повідомлення про ту саму смерть. Смерть учасника записаної гільдії збільшує її спільний лічильник. Якщо персонаж теж є в книзі, окремо збільшується його лічильник. Для цього WoW має надати читабельний ідентифікатор, а аддон має визначити персонажа або його гільдію. `COMBAT_LOG_EVENT_UNFILTERED` у Forever зарезервований клієнтом.

## Керування

- Вікно `/gb` можна пересувати за заголовок і закривати через Esc. Список прокручується й показує ніки, коментарі, авторів, час додавання та кількість смертей. Клік по кнопці пріоритету в рядку перемикає між **Звичайний** і **Високий**. Записи високого пріоритету йдуть першими. Записи зі старих версій мають звичайний пріоритет.
- За замовчуванням відкривається вкладка **Усі**. Вкладки **Персонажі** й **Гільдії** звужують список. Фільтр **Лише високий пріоритет** працює в будь-якій вкладці.
- **Додати ціль** і **Гільдія з цілі** одразу записують персонажа чи гільдію поточної ворожої цілі з коментарем із поля. Якщо ви вже ввели ім’я або назву, кнопки використовують введений текст. Якщо підхопити ціль неможливо, форма пропонує ручне введення. Гільдію можна додати за назвою без цілі, крім власної. Через правий клік по портрету ворожої цілі або фокуса також можна додати персонажа або гільдію з коментарем.
- Щоб додати запис вручну, WoW має дозволяти перевірити, що персонаж протилежної фракції, доступний для атаки та перебуває поза вашою групою й гільдією. Використайте його повне ім’я та тримайте в цілі, під курсором, у фокусі або в межах видимої іменної таблички.

| Команда | Дія |
| --- | --- |
| `/gb` або `/gb ui` | Відкрити або закрити вікно. |
| `/gb list` | Показати список персонажів і гільдій з пріоритетами в чаті. |
| `/gb add Ім’я Прізвище Коментар` | Додати ворога. Без аргументів використовується поточна ціль. |
| `/gb del Ім’я Прізвище` | Видалити запис. Без аргументів використовується поточна ціль. |
| `/gb guild add` | Додати гільдію поточної ворожої цілі. Назву в лапках можна доповнити коментарем. |
| `/gb guild del Назва гільдії` | Видалити гільдію зі списку. |
| `/gb share Ім’я Прізвище` | Запропонувати список гільдійцю. Без аргументів використовується поточна ціль. |
| `/gb share guild` | Опублікувати посилання на весь список у гільдчаті. |
| `/gb test` або `/gb test high` | Показати тестове сповіщення й відтворити звук звичайного або високого пріоритету відповідно. |
| `/gb download` | Відкрити вікно для копіювання посилання на GitHub. |
| `/gb help` | Показати підказку з командами. |

Позначте потрібні рядки або натисніть **Позначити всі** й зніміть галочки з кількох записів. Ця кнопка вибирає всю книгу, а під час зміни вкладки чи фільтра вибір зберігається. Коли жодного запису не позначено, діалог пропонує поділитися всім списком. Виберіть підказку з іменем гільдійця онлайн мишею або клавішею Tab і натисніть **Надіслати**. Кнопка **У чат гільдії** публікує посилання для всіх гільдійців з GrudgeBook. Посилання діє 30 хвилин, поки автор залишається онлайн у тій самій сесії.

Після публікації в гільдчаті з’являється підказка з адресою GitHub для встановлення або оновлення. GrudgeBook 2.2 і новіші версії приховують підказку, якщо встановлена версія така сама або новіша. Якщо отриманий список надіслали з новішої версії, у чаті з’являється посилання, яке відкриває вікно для копіювання адреси GitHub. Сумісні записи можна прийняти одразу.

В обох випадках передавання перевіряє відправника й одержувача за ростером і надсилає пакети з інтервалом 0,25 секунди. Одержувач бачить пріоритет, коментар і автора та вибирає, які записи прийняти. Для наявного запису злиття зберігає локальний коментар, більший лічильник смертей і вищий пріоритет. GrudgeBook 2.0.x сумісний із передаванням списків. Пріоритет передається між версіями 2.1.0 і новішими, а лічильники гільдій — між 2.2.0 і новішими.
