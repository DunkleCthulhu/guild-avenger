# Forever Watch

Аддон для World of Warcraft: Forever 1.60.1. Завантажте `ForeverWatch-*.zip` із [останнього релізу](https://github.com/DunkleCthulhu/forever-watch/releases/latest), розпакуйте в `World of Warcraft/_forever_/Interface/AddOns/` і ввімкніть **Forever Watch** у меню аддонів. Кожен гільдієць, який хоче отримувати сповіщення або редагувати спільний список, встановлює свою копію.

Коли поруч з’являється персонаж зі списку або учасник позначеної гільдії, Forever Watch відтворює власний звук і показує сповіщення з причиною, якщо її вказали. Сповіщення можна закрити кнопкою **×**. Кнопка **У ціль** доступна поза боєм, коли клієнт надає повне ім’я. Радіус сповіщення визначає дальність іменних табличок WoW. Увімкніть показ ворожих табличок і, за потреби, дружніх.

## Вікно та команди

Введіть `/fw`, щоб відкрити вікно. На вкладках **Персонажі** та **Гільдії** можна ввести назву вручну або натиснути **З цілі**, щоб підставити її з вибраного гравця. Поле **Причина** можна заповнити під час додавання або змінити пізніше через **Редагувати**. Коліщатко миші над списком перегортає сторінки. Кнопка **Тест сигналу** показує зразок і відтворює звук.

| Команда | Дія |
| --- | --- |
| `/fw` | Відкрити або закрити вікно списку. |
| `/fw add Ім’я Прізвище` | Додати персонажа. Без імені використовується вибрана ціль. |
| `/fw remove Ім’я Прізвище` | Вилучити персонажа. Без імені використовується вибрана ціль. |
| `/fw guild add Назва гільдії` | Додати гільдію. Без назви використовується гільдія вибраної цілі. |
| `/fw guild remove Назва гільдії` | Вилучити гільдію. Без назви використовується гільдія вибраної цілі. |
| `/fw list` | Показати список. |
| `/fw share` | Поширити свою копію списку серед гільдійців, які зараз онлайн. |
| `/fw test` | Показати тестове сповіщення і відтворити звук. |

Зміни надсилаються через внутрішній канал аддонів гільдії. Якщо хтось був офлайн, натисніть **Поширити гільдії** або введіть `/fw share`, коли той увійде. Причини бачать гільдійці з версією 0.2.0 або новішою. Пізніша ревізія запису має перевагу, а за однакової ревізії перемагає видалення. Копія списку зберігається на комп’ютері окремо для кожної гільдії. Поза гільдією команди працюють із особистим списком.

## Як долучитися

Для виправлення або нової функції зробіть форк і відкрийте pull request. Щоб перевірити зміни, скопіюйте папку `ForeverWatch` у `_forever_/Interface/AddOns/`. У грі введіть `/reload`, відкрийте `/fw` і перевірте кнопку **Тест сигналу**. У звіті про помилку вкажіть версію WoW і кроки для її відтворення.

Код і звук поширюються за [MIT-ліцензією](LICENSE).
